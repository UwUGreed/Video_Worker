Drop your quiet background track here as `lofi-bed.mp3`.

Also supported:

- `lofi-bed.wav`
- `lofi-bed.m4a`
- `lofi-bed.aac`
- `lofi-bed.ogg`
- `lofi-bed.flac`

`video_api.py` will auto-mix the file under the uploaded voice track at a very low volume by default.
You can also override the file path with `VIDEO_BACKGROUND_MUSIC` or upload a one-off `music` file to `/render`.
